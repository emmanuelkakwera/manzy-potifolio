PROJECT 01

MoneyGuard Malawi

A machine-learning web application that detects SMS phishing and fraud targeting mobile money users in Malawi, helping people identify suspicious messages before they lose money.

The problem Mobile money users receive fraudulent SMS messages designed to steal PINs and cash. Many people cannot easily tell a scam message from a genuine one.

Technologies used

Python Flask Scikit-learn Text Classification HTML/CSS/JS
GitHub repository
PROJECT 02

McCOY

An electronics shop website with product management functionality, built to give a local retailer a professional online catalogue and a simpler way to manage products.

The problem Small electronics shops often depend on physical walk-ins and manual stock records, which limits their reach and makes product updates slow.

Technologies used

HTML CSS JavaScript Flask SQL

PROJECT 03

Machili Agricultural Innovations

Corporate branding and the Ulimi Mmanja digital agriculture concept — a visual identity and digital idea designed to connect smallholder farmers with useful agricultural information.

The problem Smallholder farmers need clearer access to agricultural information and markets, while the company needed a credible identity to attract partners and customers.

Technologies & methods

Brand Identity Adobe Photoshop Digital Agriculture HTML/CSS Concept

PROJECT 04

Club Voting System

A digital voting system developed as an academic group project for the Computer and Engineering Club, replacing manual ballot counting with a faster and more transparent process.

The problem Manual club elections are slow and prone to counting errors and disputes. The system gives members a simple way to cast votes and produces clear results.

Technologies used

Java SQL Database Design UI Design
